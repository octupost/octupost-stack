## Notes

1. **Database Enums**: Types marked with "DB" suffix (e.g., `ProjectStatusDB`) match the Supabase database schema exactly.

2. **Legacy Types**: Some types are marked as legacy and kept for backward compatibility. Prefer newer alternatives where noted.

3. **Canonical Parameters**: The `CanonicalParamName` type is used to normalize different model parameter names to a consistent UI display.

4. **Pricing Units**: Pay attention to `"second"` vs `"compute_second"` - the former is predictable (video duration), the latter is only known after generation completes.
